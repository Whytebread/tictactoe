# Tic Tac Toe

A simple browser-based Tic Tac Toe game built with HTML, CSS, and JavaScript.

## Features

- 3x3 interactive game board
- Two-player gameplay with custom player names
- Random starting player for each new game
- Turn display and win/tie detection
- "Start New Game" and "Reset" buttons to restart or clear the board

## How to Use

1. Open `index.html` in your browser.
2. Enter names for Player One and Player Two, or leave the fields blank to use the default names.
3. Click any square to place the current player's symbol.
4. The game automatically detects a winner or a tie and displays the result.
5. Click "Start New Game" to begin a fresh match with a new random starting player.
6. Click "Reset" to clear the board and keep the same game session.

## Files

- `index.html` — game layout and UI structure
- `main.css` — styling for the board, buttons, and player display
- `main.js` — game logic, board state, player control, and rendering

## Notes

- The game runs entirely in the browser and does not require any server or build tools.
- Player symbols are fixed to `X` and `O`.
